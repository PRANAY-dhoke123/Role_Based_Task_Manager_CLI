# Role_Based_Task_Manager_CLI
 SO This project is purely on the OOPS concepts and python

 Name of Project : Role Based Task Manager 


 Flow :

 After running the file the user get Menu-Driven Program
in this    
        Login as 
            1. Admin  
            2. Manager 
            3. Empployee
            4. exit 


Admin menu 
1. Add Employee
2. Delete Employee
3. View Employee Details
4. View All Employees
5. Logout
    
Manager menu 
1. Create Task
2. Assign Task
3. View All Tasks
4. View Task Status
5. Logout
    
----------------------------
Create Task                 |
     ↓                      
Assign Task to Employee 
     ↓
Employee receives task
     ↓
Employee works on task
     ↓
Employee updates status
     ↓
Manager views task status

Employee menu 
1. View My Tasks
2. View Task Details
3. Update Task Status
4. Logout




                    ROLE-BASED TASK MANAGER
                             |
              +--------------+--------------+
              |              |              |
            Admin          Manager       Employee
              |              |              |
        Add Employee     Create Task     View Tasks
        Delete Employee  Assign Task     Task Details
        View Employee    View Tasks      Update Status
        View All         Task Status
